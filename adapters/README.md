# Adapters

One directory per adapter id:

```
adapters/<id>/<version>.yaml      the descriptor (canonicalised + hashed)
adapters/<id>/fixtures/*.json     the gate's mint/test vectors
```

Descriptors are authored per [CONTRIBUTING.md](../CONTRIBUTING.md), gated by the
`adapter-gate` workflow on pull requests, and published by `registry-publish` on
merge into `main`. A version becomes globally pinnable and signed only on a
maintainer verdict (`verdict:list` on the merged PR, or a
`Registry-Verdict: list` commit trailer) — merging alone never lists anything.

`registry.json` at the repo root is generated by `tools/publish/regen.py`.
Never hand-edit it.
